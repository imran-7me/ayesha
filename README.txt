ROMANTIC PROPOSAL WEBSITE

1. Open index.html in a browser to preview.
2. To personalize it, edit the text in index.html using VS Code.
3. To publish free with GitHub Pages:
   - Create a new public GitHub repository.
   - Upload index.html (or upload all files in this folder).
   - Open Settings > Pages.
   - Under Build and deployment, choose Deploy from a branch.
   - Select main and / (root), then Save.
   - After publishing, copy the GitHub Pages URL and send it in Messenger.

The NO button respects the other person's choice; it does not move or pressure them.
